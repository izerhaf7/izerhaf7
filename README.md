### 🔧 Featured work
- **[Satu Muatan](https://github.com/izerhaf7/satu-muatan)** 🥉 *3rd place, ITFEST 2026 Software Development Competition*: lets small-scale farmers share one truck on the same corridor, with a price that never goes up and trip evidence for quality disputes. FastAPI, PostgreSQL, React + TypeScript.
- **[Transense](https://github.com/izerhaf7/transense)**: TransJakarta trip info for Deaf riders, turning audio-only announcements into visual and haptic alerts. React + Vite PWA, FastAPI + WebSocket, Vercel and Cloud Run.
- **[Lyla](https://github.com/izerhaf7/lyla-agent)**: an Indonesian voice and text task assistant for students, with a desk companion device. ESP32-S3 firmware (PlatformIO), FastAPI + Google ADK, React dashboard, AWS EC2.
- **[Quantivo AI](https://github.com/izerhaf7/quantivo-ai)**: a SaaS that generates business opportunity analyses from AI and real data. FastAPI, React + TypeScript, Qdrant, Redis, nginx.
